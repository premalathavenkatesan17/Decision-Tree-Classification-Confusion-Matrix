# Decision Tree Classification and Performance Evaluation Using Confusion Matrix

## 📌 Project Overview

This project implements a **Decision Tree Classification model** using the **Iris Flower Dataset**. The performance of the trained model is evaluated using an **Accuracy Score, Confusion Matrix, and Classification Report**.

## 🎯 Aim

To implement Decision Tree Classification and evaluate the performance of the model using a Confusion Matrix.

## 📊 Dataset

The **Iris Flower Dataset** is used for this project.

### Features

* Sepal Length
* Sepal Width
* Petal Length
* Petal Width

### Target Classes

* Iris-setosa
* Iris-versicolor
* Iris-virginica

## 🛠️ Technologies Used

* Python
* Google Colab
* Pandas
* Matplotlib
* Scikit-learn

## ⚙️ Algorithm

1. Import the required libraries.
2. Upload and load the Iris dataset.
3. Separate input features and the target variable.
4. Split the dataset into training and testing sets.
5. Create the Decision Tree Classifier.
6. Train the model using the training data.
7. Make predictions using the testing data.
8. Calculate the accuracy score.
9. Generate the Confusion Matrix.
10. Display the Classification Report.
11. Visualize the Decision Tree.

## 📈 Performance Evaluation

The model performance is evaluated using:

* Accuracy Score
* Confusion Matrix
* Classification Report
* Precision
* Recall
* F1-Score
